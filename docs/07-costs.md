# Slopdar — Costs

## 100% free (open-source, self-hosted on the VPS)

Next.js, MySQL, Prisma/Drizzle, Auth.js, Tailwind, Framer Motion, Playwright,
Cheerio, Redis, Satori/share cards, Caddy/Nginx, PM2, Umami.

**The entire tech stack is free.**

## What actually costs money

| Thing | Cost | Notes |
|---|---|---|
| Domain `slopdar.com` | ~$10–12 / year | Unavoidable |
| VPS | already owned | No new cost |
| Google login setup | free | Google OAuth is free |

**Bottom line: only real cost to launch is the domain (~$1/month).**

## Optional future costs (not needed now)

- **LLM copy analysis** — if we later use an LLM (e.g. Claude) to judge website
  text more cleverly, that API has a cost. Start with free regex/pattern rules.
- **Email sending** — free tiers exist (e.g. Resend); only if we add email.
- **Bigger VPS** — only if traffic grows a lot. Good problem to have.
