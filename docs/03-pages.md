# Slopdar — Pages

## Page map

```
Home
 ├─ Result page    →  Share card
 ├─ Leaderboard    (Wall of Shame / Hall of Fame / Recent)
 ├─ Compare two sites
 ├─ Badge page
 ├─ How it works
 ├─ About
 └─ Profile (login)
```

## 1. Home page

- Big input box: "Paste any website link here"
- One button: "Check the Vibe"
- A few example results (famous sites already checked)
- Live counter: "12,438 sites checked so far"
- Short explainer: "We scan a website and detect signs of AI / vibe-coding."

## 2. Result page (most important — where sharing happens)

- The **Slop Score** — big number, 0–100
- The **tier / label** (🛠️ Hand-Crafted → 🤖 Pure Slop)
- A **roast line** — funny one-liner verdict
- The **proof (receipts)** — exactly what we found, item by item
- **Screenshot** of the website
- **Tech stack detected**
- **Share button** → generates the image card (X / LinkedIn / WhatsApp)
- **"Check another site"** button

## 3. Leaderboard / Hall of Fame

- **Wall of Shame** 🤖 — most AI/vibe-coded sites checked
- **Hall of Fame** 🛠️ — most hand-crafted sites
- **Recently Checked** — live feed

## 4. Compare page

- Two website links side by side
- Which one is more vibe-coded
- Great for "me vs my competitor"

## 5. Badge page

- Grab a badge: "Certified Hand-Coded 🛠️" / "Proudly Vibe-Coded 🌊"
- Copy-paste embed code
- Each badge links back to Slopdar (free marketing)

## 6. How it works

- Simple explanation of the signals we check
- Honest note: "We detect *signs*, not 100% proof — it's for fun"

## 7. About / Story

- Who built it (Mukund), why, the joke behind it
- Indie-hacker personality

## 8. Profile / History (optional, logged-in)

- All sites you've checked
- Saved favorites
- Track a site over time
