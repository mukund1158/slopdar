# Slopdar — Overview

> **Is it built or is it slop?** 🛰️

## The one-line idea

A website where anyone can paste a link, and Slopdar tells them whether that
website looks **hand-coded by a real developer** or **vibe-coded / made by AI** —
with a fun **Slop Score**, the proof behind it, and a shareable result card.

## Why this exists

In today's era, almost everyone ships products that are vibe-coded or
AI-generated. But there is **no platform** where people can check whether a
project, product, or website was vibe-coded or AI-generated. Slopdar fills that
gap — as a fun, viral, curiosity-driven tool.

## The core loop

```
Paste a URL  →  Get a Slop Score (0–100)  →  See the proof  →  Share it
```

Everything in the product exists to support this single loop.

## Direction (decided)

- **Input:** Website URLs
- **Tone:** Playful / meme-y (viral-first, levelsio energy)
- **Wedge:** Curiosity & virality (shareable scores, badges, leaderboard)

## The honest framing (important)

We **cannot 100% prove** a site is "AI generated" — and claiming certainty
invites blowback. So Slopdar reports **"vibe signals detected,"** not "verdict of
truth." Evidence-first, confidence-weighted. It is funnier *and* more defensible
to say *"we found 7 tells"* than *"this is 92% AI."*

## Meta-twist (lean into it)

Slopdar's own stack (Next.js + Tailwind + MySQL) is itself a "vibe-coding" stack.
Footer line: *"Yes, Slopdar runs on the slop stack. We know. 🌊"*
